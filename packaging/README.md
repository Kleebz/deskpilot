# Publishing to the AUR

Everything here is generated by the release workflow; this is the part a person
has to do, once.

## Before it can work at all

**The repository must be public.** AUR packages build on other people's
machines, unauthenticated, so `source=` has to be a URL that anyone can fetch.
While the repo is private the release URL returns 404 and every build fails:

```
curl -sI https://github.com/Kleebz/deskpilot/releases/download/v0.1.0/deskpilot-0.1.0-x86_64.tar.gz
```

That must be a 200 before going further. If the repo has to stay private, the
alternative is hosting release artifacts somewhere public and pointing `source=`
there instead.

## Once

1. Make an account at <https://aur.archlinux.org/register>.
2. Add an SSH public key to it, under My Account. Generate one if needed:
   `ssh-keygen -t ed25519 -C aur`
3. Tell ssh to use it:

   ```
   Host aur.archlinux.org
     User aur
     IdentityFile ~/.ssh/id_ed25519
   ```

## Publishing a version

The release workflow attaches a `PKGBUILD` with the real version and checksum
already filled in, so this is a copy rather than an edit:

```
git clone ssh://aur@aur.archlinux.org/deskpilot-bin.git aur-deskpilot
cd aur-deskpilot
gh release download vX.Y.Z -p PKGBUILD --clobber
makepkg --printsrcinfo > .SRCINFO      # AUR requires this, and rejects a stale one
makepkg -si                            # build and install it locally first
git add PKGBUILD .SRCINFO
git commit -m "deskpilot-bin X.Y.Z"
git push
```

Build it before pushing. A broken PKGBUILD in the AUR is visible to everyone
who tries to install it, and the fix is another commit rather than an undo.

## Why -bin

The package installs a prebuilt release instead of compiling. Building from
source would need Deno and npm on every user's machine, which is the toolchain
the single binary exists to remove.

`desk.sh` is installed to `/usr/share/deskpilot/scripts/` and that path is not a
convention. The binary's subprocess allowlist is fixed when it is compiled, so
that is the only copy it may execute — a copy anywhere else is found and then
refused, which looks exactly like "this machine has no compositor". If the
install path ever changes, `shell/build.sh` and `PKGBUILD` have to change
together.
