ONE PROPOSAL · DESIGN REVIEW · SAMPLE DATA

One hierarchy. More room for work.

Spaces → tabs → terminals. The same navigator stays on the side of a wide screen and opens from the top of a phone. This is the proposed final layout, with its key states together for review.

Try Spaces, search, tab expansion, terminal switching, Hide / Restore, Computer, and pairing cancellation. Terminal output, input, management, pairing and updates are simulated. This review never connects to your computers.

One navigator

A persistent desktop sidebar becomes a top-opened mobile drawer. Remove the duplicate bottom dock and horizontal tab/pane strips.

Keep the terminal in place

Opening navigation or changing screen width keeps the terminal and composer mounted. Previous/next and horizontal swiping stay within the current tab.

A quieter backlog

Available conversations starts collapsed. Search includes available work; hidden work has an explicit Show hidden / Restore path. No age-based removal.

Clear computer context

Computer, source and connection stay visible. Computer contains switching, Desktop, Previews, pairing and settings.

Reliable gestures and drafts

Vertical movement scrolls history. Horizontal movement switches sibling terminals. Drafts stay with their exact source. Back dismisses the keyboard and overlays first.

A visible update path

Show when a new UI is ready and offer a deliberate reload. Keep UI and backend versions distinct in settings; keep saved pairings and drafts.

Release boundary: one visible terminal on every screen size; native Herdr ownership stays native; existing terminal transport and desktop tools are preserved. A simultaneous multi-terminal grid is outside this change. The full scope and release checks are in the final specification.
